## Product or concept
TrustLens — Solana transaction intelligence. Beat: a pasted transaction signature
becomes a verified swap verdict (2.4 SOL → 312.86 USDC via Jupiter), backed by
source evidence and a historical-price estimate. 12 seconds, silent, 1280×720,
plays inside the app's own video player. All on-screen numbers come verbatim
from the demo fixture (`src/lib/demoReport.js`, user-supplied authoritative data
for this demo branch); nothing invented.

## Authoritative sources
- Own product UI: `src/components/LiveReport.jsx` (What-moved summary, findings,
  evidence, trade blocks) — visual language source of truth.
- Own brand: blue/white editorial (`#f5f7ff` bg, `#122145` ink, `#315ed8` blue,
  Arial/serif mix), `TRUSTLENS · STATUS · KIND` eyebrow from `server/remotion/index.jsx`.
- Demo fixture values: headline, 2.4 SOL / 312.86 USDC, 5000-lamport fee,
  −0.34% estimate. No external logos used (none needed; no marks redrawn).

## Real visual language
Light editorial report surface. Eyebrow label, headline, net-movement lines
(sent/received with amounts), progress rule, finding cards, evidence excerpts
with source titles, closing verdict line. Blue progress accents, flat fills,
no glow.

## Closest approved mechanism
`openmontage-claude-pipeline`: sequential production workflow — input (signature)
→ decode (movements) → evidence (sources) → verdict (share-ready). One connected
report world; camera follows causality input → work → output; each stage is a
distinct step with travel bridging them. New concept (report-timeline) inheriting
its camera grammar, restraint, and causal motion. Single mechanism, no combo.

## Motion plan
360 frames @30fps. Hold on signature input (0–2s) → travel down the report as
each block resolves: headline → what-moved lines draw via progress rule →
findings → evidence excerpts → trade estimate → verdict hold (10–12s stable).
Springs for block entrances, interpolate for progress/rule draws. Fewer, larger
focal objects; current stage centered and readable at 720p.

## Avoid
Neon/glow/gradients/glassmorphism; receipt/dossier/card-grid props; invented
numbers, logos, prices, or claims; slow-zoom-only camera; narration text
(silent); dark void backgrounds; redrawing Jupiter/Solana marks (no logos used).
